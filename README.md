# 🏅 Olympic Games Data Analytics (1896–2024)

## 📌 Project Overview

Olympic Games Data Analytics is a Data Analysis and Visualization
project based on historical Olympic Games data from 1896 to 2024.

The project analyzes Olympic participation, medals, countries,
sports, gender participation, and trends over time.

An interactive Plotly Dash dashboard is also developed to allow
users to explore medal information for different countries/teams.

---

## 🎯 Problem Statement

The Olympic Games generate a large amount of historical data
containing information about athletes, countries, sports, events,
and medals.

The objective of this project is to analyze this data using
Python and identify meaningful patterns and trends in Olympic
participation and medal distribution.

---

## 🎯 Objectives

- Analyze medal distribution by country/team.
- Analyze medal distribution across different sports.
- Study Olympic trends across years and decades.
- Analyze male and female participation.
- Explore relationships between numerical variables.
- Detect outliers in numerical data.
- Create meaningful data visualizations.
- Develop an interactive Olympic medal dashboard using Plotly Dash.
- Use AI tools to support analysis, coding, and debugging.
